# Portfolio Website

A responsive, single-page portfolio website built with HTML and CSS.

## Preview

Open `index.html` directly in a browser, or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000/index.html`.

## Customize

- Update the name and email in `index.html`.
- Replace the abstract portrait and project mockups with your own images.
- Change the project names, descriptions, and section links.
- Edit the colors in the `:root` section of the embedded CSS.
